# ROADMAP

## 完成形

外注者がWeb画面から商品画像と `_SUCCESS.txt` を登録し、AI生成後に運用者が同じ画面で内容と画像順を確認・修正・承認します。承認済み商品だけをメルカリShops公式CSVとしてダウンロードし、メルカリShops側で最終確認して出品します。

## フェーズ

| フェーズ | 目的 | 主な内容 | 完了条件 |
|---|---|---|---|
| Phase 1A | 承認フローを正式版にする | Review UI、Sheets同期、編集、画像並び替え、承認、公式CSV | PR #6をmainへ統合し、main由来のCloud Runを稼働させる |
| Phase 1B | 日常運用に耐えられることを確認する | batch分離、リトライ、エラー復旧、10商品試験 | 異なる2日分の10商品batchが混ざらず、再実行でも重複しない |
| Phase 2 | アップロードもWeb画面へ統合する | batch作成、複数商品の画像・`_SUCCESS.txt`登録、進捗・エラー表示 | GCS画面を開かず、登録からCSV取得までReview UIだけで完了する |
| Phase 3 | 複数人の本番運用を安定させる | 権限分離、操作履歴、通知、監視、バックアップ、保存期限 | 誰が何を変更したか追跡でき、失敗を検知・復旧できる |
| Yahoo検証 | Yahoo向け出力を正式運用にする | 実際の一括出品環境へCSV投入 | 実投入結果と必要な修正が記録される |

## 現在地

Phase 1Aの機能実装と実機検証は完了しています。

- Cloud Run上のReview UIへGoogleログインできる
- 商品一覧、画像、編集画面が表示できる
- カテゴリ検索、価格入力、画像のドラッグ並び替えができる
- Save / Save & Approveができる
- 承認済み商品だけを公式88列・UTF-8 BOM付きCSVへ出力できる
- 署名付き画像URLを含むCSVをメルカリShopsへ実際にアップロードできる

残っているのは、PR #6のmain統合と、実データによる複数batch・リトライを含む運用耐性確認です。10商品×2batch、同一イベント再実行、別batch分離は自動テストを追加済みです。

## 完成判定

次をすべて満たした時点を、メルカリShops向けツールの完成とします。

1. 10商品を含むbatchを異なる日付で2回処理しても商品が混ざらない
2. 同じイベントを再実行してもSheets・review・CSVに重複しない
3. `_SUCCESS.txt`不足と読み込み障害を別のエラーとして確認できる
4. Review UIで修正・承認した内容だけが最終CSVへ入る
5. 最終CSVをメルカリShopsへ取り込める
6. 操作手順、障害時の復旧手順、CSV再生成手順が文書化されている
7. mainのコードと稼働中サービスの版が一致している

## 運用上の前提

- AI生成結果は必ず人間が確認する
- `Generate CSV` 後7日以内にメルカリShopsへアップロードする
- 期限を過ぎたCSVは再生成して署名付き画像URLを更新する
- mainマージと本番デプロイはユーザー承認後に行う
